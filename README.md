# Referência TIC – busca de compras públicas de referência

Ferramenta acadêmica (UnDF + CeTI/PMDF) que encontra o código do catálogo de um produto, busca compras públicas homologadas parecidas (últimos 12 meses) com preço e link oficial do PNCP, e prepara o TR para leitura por IA.

- **Usar online:** https://referencia-tic-app.streamlit.app
- **Usar no computador:** ver LEIA_ME.md
- Só dados públicos. A busca não usa IA. Estudo de viabilidade (MVP), não sistema oficial.
